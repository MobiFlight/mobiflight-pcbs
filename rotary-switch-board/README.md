# Rotary switch board

This module uses the "SR16" rotary switch that can be found in 2 to 8 position variants, with 45 degree rotation between positions.

![image](kicad-board-exports\rotary-switch-board-top.png)

The board has a resistor ladder and should be wired to an analog input like it was in thea potentiometer. Each switch position will have a fixed analog value.

The switch has a panel mount thread and a nut, so the 20x20 is just an alternative way to mount it the same way as the other 20x20mm mounted boards.

This board features a soldering footprint for the rotary switch, a 3-pin JST-XH connector that connects to the Potentiometer connector on the [MobiFlight Prototyping Board](https://shop.mobiflight.com/product/prototyping-board-v2/). The resistors ladder components are surface mount type.

This repository contains the KiCad project files. If you are interested in this board, you can also find it in the [MobiFlight Community Shop](https://shop.mobiflight.com/product/rotary-switch-bundle).
